# ZYNT FILMS v2

Обновление на базе текущего GitHub-проекта ZYNT FILMS.

Добавлено:
- поиск пользователей по ID;
- ручная выдача/удаление подписки;
- блокировка/разблокировка;
- уведомления о назначении/снятии администратора;
- медиа через Telegram file_id;
- промокоды с независимыми днями и скидкой 0/5/10/25/50/70/100%;
- удаление промокодов;
- реферальные уровни 5/10/15%;
- +3 дня один раз после 10 приглашённых с первой оплатой;
- реферальный расчёт от фактически оплаченных Stars;
- защита от повторного засчёта реферала;
- блокировка на уровне middleware;
- сохранение `.env`/БД на сервере.

Перед установкой проверьте файлы и сделайте резервную копию базы.
