# ZYNT FILMS — production-oriented v1

Python 3.11+ / aiogram 3 / SQLite / Telegram Stars.

## Возможности
- обязательная подписка на каналы с реальной проверкой через getChatMember;
- каналы добавляются через админку;
- единый экранный UI с кнопками;
- экранные картинки настраиваются через админку;
- каталог фильмов: видео + номер + название + описание + год + жанр + постер;
- Telegram Stars: 7/30/90 дней = 129/349/649 Stars;
- проверка цены и валюты на pre-checkout;
- защита от повторной выдачи платежа по charge_id;
- продление от текущего срока;
- профиль, поиск, просмотры;
- промокоды с лимитом и one-use per user;
- администраторы и главный владелец;
- базовая рассылка копированием исходного сообщения с сохранением медиа и его inline-клавиатуры.

## Первый запуск
1. Python 3.11+
2. `python -m venv .venv`
3. Windows: `.venv\Scripts\activate`
4. `pip install -r requirements.txt`
5. Скопировать `.env.example` в `.env`
6. Вставить НОВЫЙ токен в BOT_TOKEN.
7. `python bot.py`
8. Открыть бота и `/admin`.

## Безопасность
Токен, который пользователь ранее отправил в чат, нельзя считать секретным. Его необходимо отозвать/перевыпустить в @BotFather. Новый токен не хранится в репозитории и задаётся только через `.env`.

## Каналы
Добавляй публичный канал как `@username`. Бот должен быть администратором канала, иначе Telegram не гарантирует работу getChatMember для проверки других пользователей.

Для приватного канала добавляй `@username/ID | invite_url` (если Telegram возвращает доступный chat_id).

## Stars
Для цифрового доступа Telegram требует использовать Stars с валютой XTR. Для invoice не нужен provider token. Бот принимает pre_checkout и выдаёт доступ только после successful_payment.
